## 🚀 System Overview
**InatGebeya** is a powerful, secure, and highly responsive multi-vendor e-commerce platform designed to bridge the gap between local vendors and modern consumers. Built with a focus on data integrity, security, and automated operations.

### 🏗️ Project Architecture
The system is divided into two main repositories:

1.  **[Backend (API Server)](./Back_End/README.md):** 
    - Powered by **Node.js** and **Express.js**.
    - Robust **MySQL** database integration.
    - Dual-layer security with **JWT** and **express-validator**.
2.  **[Frontend (User Interface)](./Front_End/vite-ecommerce/README.md):**
    - Built with **React 18** and **Vite**.
    - Styled with **Tailwind CSS** for a premium, responsive feel.
    - Integrated with **React Router** for seamless navigation.

## ✨ Key Differentiators (Why InatGebeya?)

### 1. Automated Stock Management
Most local platforms suffer from "phantom inventory"—displaying items that aren't actually available. InatGebeya solves this with **Real-Time Stock Sync**. As soon as an item sells out, it is automatically hidden from the storefront.

### 2. Multi-Vendor Security
Our system enforces strict **Shop Owner Isolation**. Each vendor has their own secure environment where they can manage inventory and sales without seeing or affecting other vendors' data.

### 3. Identity & Access Lock
To prevent common forms of account hijacking, critical user details (like Email) are made **immutable** after verification. Additionally, the system features a dedicated "Blocked User" handling system for administrative control.

### 4. Enterprise-Grade Validation
Every input is scanned twice: once on the **Client-side** for a fast user experience, and once on the **Server-side** using rigorous industry standards to block any malicious data manipulation.
