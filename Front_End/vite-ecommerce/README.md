# InatGebeya E-commerce Frontend

A modern, high-performance, and visually stunning React-based frontend for the InatGebeya E-commerce platform.

## 🌟 Tech Stack

- **Core:** React 18 (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Navigation:** React Router Dom
- **API Client:** Axios
- **Notifications:** React Hot Toast
- **UI Components:** Headless UI

## 📋 Prerequisites

- Node.js (>= 16.x)
- npm or yarn

## 🛠️ Setup & Installation

1. **Navigate to the frontend directory:**
   ```bash
   cd Front_End/vite-ecommerce
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Environment Configuration:**
   Create a `.env` file in the root:
   ```env
   VITE_API_BASE_URL=http://localhost:5000
   ```

## 🏃 Scripts

- **Start Development Server:**
  ```bash
  npm run dev
  ```
- **Build for Production:**
  ```bash
  npm run build
  ```
- **Preview Production Build:**
  ```bash
  npm run preview
  ```

## ✨ Key Features

- **Responsive Design:** Optimized for Mobile, Tablet, and Desktop.
- **Role-Based UI:** Dynamic dashboards for Admins, Shop Owners, and regular Users.
- **Theming:** Full Support for Light and Dark modes.
- **Cart & Checkout:** Seamless shopping experience with shop-specific item grouping.
- **Dynamic Shop Management:** Rich inventory views for sellers.
- **Animations:** Smooth transitions and micro-interactions.

## 📁 Folder Structure

- `src/components/`: Reusable UI components (forms, layouts, feedback)
- `src/context/`: State management (Auth, Cart, Theme)
- `src/pages/`: Page-level components
- `src/routes/`: Routing logic
- `src/api/`: Axios instances and endpoint helpers
- `src/utils/`: Formatting and navigation helpers
- `src/assets/`: Static files and images
